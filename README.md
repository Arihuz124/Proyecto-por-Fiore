# Proyecto 02 — Esta es por Fiore

Proyecto académico de **Desarrollo de Aplicaciones Web y Móviles de ESPOL**, desarrollado por **Arihuz Icaza y Sebastián Toral**.

## Descripción

Este proyecto presenta un sitio web sobre la maratón solidaria **“Esta es por Fiore”**, realizada el **3 de octubre de 2026 en la urbanización Puerto Azul**. La actividad reunió a corredores, familiares, acompañantes y organizadores con el propósito de recaudar fondos para apoyar una intervención quirúrgica.

La página documenta la jornada mediante información del evento, fotografías y testimonios. A través de este contenido, se busca mostrar cómo una actividad deportiva puede reunir a la comunidad alrededor de una causa solidaria.

## Objetivo

Aplicar los conocimientos de desarrollo web para presentar una actividad de la comunidad y dar a conocer las motivaciones, experiencias y propuestas de mejora de las personas que participaron en ella.

## Contenido del sitio

- **Inicio:** presentación del evento, fecha y lugar.
- **La maratón:** descripción de la actividad y su propósito solidario.
- **Testimonios:** fragmentos y resúmenes de cuatro entrevistas.
- **Galería:** fotografías de distintos momentos de la jornada.
- **Aprendizajes:** propuestas relacionadas con la difusión, el acceso y la comunicación de la experiencia.
- **El proyecto:** información sobre el trabajo académico y el material recopilado.

## Recopilación de información

Se utilizaron cuatro entrevistas, identificadas como **E01, E02, E03 y E04**, junto con el registro fotográfico del evento. Las respuestas permiten conocer las razones para participar, los aspectos valorados y las sugerencias para futuras iniciativas.

Los testimonios se presentan mediante códigos para conservar el anonimato. Los resultados describen las experiencias de las cuatro personas entrevistadas y no se generalizan a toda la comunidad.
